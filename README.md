# Mi espacio creativo

Landing page responsive creada con HTML, CSS y JavaScript puro.

## Cómo visualizarla
1. Descarga y descomprime el proyecto.
2. Abre `index.html` en tu navegador. También puedes abrir la carpeta en Visual Studio Code y usar una extensión como Live Server.
3. Para cambiar el contenido, edita `index.html`; para cambiar colores y estilos, edita `styles.css`; para cambiar interacciones, edita `script.js`.

## Interacciones incluidas
- Menú móvil.
- Filtros de proyectos por categoría.
- Animaciones discretas al aparecer en pantalla.
- Validación del formulario y preparación de un correo mediante `mailto:`.

## Antes de publicar
- Sustituye los proyectos conceptuales por proyectos propios o identifícalos claramente como ejercicios conceptuales.
- Cambia el correo `hola@miespaciocreativo.com` por tu correo real en `index.html` y `script.js`.
- El formulario es una demo de frontend: no guarda mensajes en una base de datos. Para eso hace falta un backend y una API.
- La tipografía se carga desde Google Fonts; si no hay conexión, se utilizarán fuentes de respaldo.
